# 微信后台发布与有界恢复

仅在编辑或发布时读取本文件。具体工具方法以当前已安装Browser/Chrome技能及运行时文档为准，不把历史插件版本、tab ID、二维码、token或坐标固化进技能。

## 接入与账号

1. 用户选定Chrome时必须使用Chrome。工具发现、初始化、必读文档和失败恢复依照该技能；复用已连接browser和有效tab，不反复初始化，不读Cookie、浏览器profile或登录存储。
2. 确认当前账号名称。已有编辑页先读标题与实际正文；只有编辑页丢失时才从`https://mp.weixin.qq.com/`进入已登录账号的草稿箱，按标题与内容找到原稿。
3. 草稿卡片的标题可能打开临时阅读页，而非编辑器。编辑按钮可能仅hover后出现：根据新DOM/截图选择真实编辑入口，等新tab出现再绑定。
4. 仅保留必要的编辑/预览tab；结束时用当前运行时支持的handoff/deliverable标记保存需要用户处理或实际交付的页面。不要关闭用户原有页面或其他线程浏览器。

## 低调用量编辑

- 可机械复用的标题、作者、摘要、结构化正文只填写一次。标题和正文可能同为`.ProseMirror`，先核对真实DOM和个数再定位。
- 外链图片正常浏览不意味着微信会导入它。稳定方式是下载到本地→通过正常上传控件上传→读取当前图片原生DOM→CLI重新生成有原生图片的粘贴HTML。
- 在正常上传按钮点击前监听当前运行时支持的filechooser事件，再传入已核实的绝对文件路径。遇到`Not allowed`读取对应官方上传排障文档，不伪造文件选择或越过扩展权限。
- DOM中读取已上传图片的`outerHTML`、`src`、加载状态和尺寸，属于必要的可见内容核验。不能调用编辑器内部保存函数、改innerHTML或读隐藏认证状态。
- 将原生图片映射写入`native-images.json`后重新`render`，正常通过HTML剪贴板粘贴。需要替换时仅替换正文，保留标题等字段。再次核对全文和图片，不留占位、不重复段落。
- 可访问性快照可能不列出`alt=""`的图片。核对实际图片DOM的`complete`、`naturalWidth`和实际截图，不能仅凭快照无`img`判定没图。
- 窄窗口可能让按钮在视口外，语义`click`看似返回但没有触发。读新DOM/截图确认后，可对真实按钮使用正常键盘`press('Enter')`；不要为适配编辑器随意放大viewport或盲点坐标。
- 将互不依赖的少量操作合入一次工具调用，但不批量执行还未知的发布确认。工具总timeout覆盖预计调用耗时，长操作及时yield；不要沿用会导致运行时重置的过短默认超时。

## 配图、封面与声明核验

- 至少一张相关图片加载完整，正文位置与图注正确。封面实际背景缩略图与裁切正常。
- 选封面后，后台可能仍保留“拖拽或选择封面”字样；核对真实封面预览背景/截图及保存结果，不能只看这个通用文案判断失败或成功。
- 选择已有正文图作封面，检查横版与方形裁切，关键人物与标题不被切掉。不在图片范围内滚轮滚动弹窗，以免误缩放；坐标动作必须来自新截图。
- “创作来源”标题可能不是交互入口。先检查该行真实控件，再打开选项并选择适用声明；确认后看到已选文案，保存后再核实。
- 用户已要求后续每篇原创，确认正文符合平台原创条件后正常声明「文字原创」，核对作者和协议，再保存验证实际已选文案；仍保留适用的AI创作来源与第三方素材说明。「赞赏」独立设置，不因声明原创而开启。
- 每篇勾选「原文链接」，正常填写`https://manying.site/`。检查保存后的网址、正文中的自然网站介绍，以及公开页「阅读原文」入口。
- GIF须检查正文位置、多帧动画与微信实际GIF加载；不要用静态预览代替动画核验。视频采用正常原生上传和播放控件，检查实际播放结果。

## 保存、发布与幂等

1. 保存为草稿后，读真实保存时间、版本表或成功回执。截图与阅读预览核对当前版本；旧临时预览会保留早先无图正文，刷新旧链接未必得到新版本。
2. 点击“发表”可能只进入群发通知/定时选择，再进入“继续发表”，再要求微信验证。逐步读取真实页面，只操作已观察到的下一步。
3. 群发次数是有限资源。不要为了测试重复提交，群发、定时和分组按用户授权与当天后台实际额度处理，不固定“每天必有1次”。
4. 出现管理员验证二维码时，记录`awaiting-admin`，保留验证页面，明确请管理员/运营者微信扫码并确认。二维码不存入技能、日志、仓库或Personal Brain。
5. 用户说完成验证后，首先读取后台状态和发表历史，再决定是否有待完成的步骤。无明确失败证据，不再次点击提交。
6. 只有后台已发表记录和新的实际公开阅读页匹配标题、正文、图片与时间后才记`published`。正式URL不能是临时预览、带认证参数的编辑页或后台管理页。

## 有界恢复与停止点

| 观察到的问题 | 处理 | 不能做 |
| --- | --- | --- |
| 工具返回后页面没变化 | 新DOM/截图核对控件与焦点；对已确认按钮尝试一次键盘触发 | 连续重复点击发布 |
| 图片导入失败 | 换本地正常上传，读取原生图片DOM重建正文 | 把无图稿当完整稿发布 |
| 读取/连接超时 | 保存最近断点，按当前浏览器技能做一次有界恢复 | 私接CDP/Playwright、无限重试 |
| tab失效、编辑页丢失 | 从当前browser列tab；必要时进入已登录草稿箱找原稿 | 重选browser、重复新建同题文章 |
| 上传权限被拒绝 | 官方上传排障；需要用户开启权限时明确请求 | 擅改安全配置或伪装文件选择 |
| 扫码/验证码/登录失效 | 保留页面，记录实际阻塞并请求用户处理 | 用别的接口绕过验证 |
| 发布调用超时/结果不明 | 记`uncertain`；先只读查已发表记录与公开文章 | 把超时当失败再次发表 |
| 用户让停止或只整理skill | 停止发文，只进行所要求的整理 | 边整理边继续提交 |

CLI不创建浏览器控制后台。需要修复自有辅助程序时遵守本机隐藏窗口约定；服务重启或扩展重装不能从“继续发文”无限扩大推断。新的账号、安全权限、法律声明或无法恢复的验证是明确停止点。
