# 单 agent 持续任务生命周期

当前执行规则以[主线程流程](main-supervision.md)和[短入口](low-token-workflow.md)为准。一个原生 Goal、一个业务 agent 顺序完成 Playwright、资源审计、封面、ACK、生产增量与验收。无需宿主接力、采集子线程、额外监督进程或系统计划任务。

正式主绑定和唯一共享协调状态决定 owner/work；每个有界 CLI 返回之后继续下一步或按持久轮询断点等待。持续运行权限来自用户明确开启/继续授权；用户暂停或正式停工后，只有新明确复工指令可恢复。旧四路生命周期、故障台账、任务书、句柄与证据作为历史保留，不重新启用。
