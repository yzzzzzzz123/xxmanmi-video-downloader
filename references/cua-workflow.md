# CUA：发现页面与分集

## 建立任务标签

使用本轮可用的 CUA 入口；首次调用只执行工具说明允许的初始化调用，阅读返回文档后继续。发生上下文压缩后按工具要求重读文档。原生 Chrome 控制与 CUA 浏览器接口均可，但实际操作要遵守当前接口的限制。

优先接管用户明确给出的站点标签。没有合适标签时，仅新建一个任务标签，不占用用户正在播放视频的其他标签。记录任务标签身份/原始 URL。每次输入前检查新界面；用户改动使旧索引失效时重新读取状态。

打开开发者工具并通过实际菜单选择右侧停靠。已有工具面板不要再次按快捷键把它关闭。资源列表与资源详情都在此任务标签导航；不能批量新开资源页。普通点击若会 `target=_blank`，读取/复制界面中已出现的链接，在原标签地址栏粘贴并回车；返回列表同样使用已保存的真实 URL。不要通过修改站点事件、批量脚本点击或篡改 target 来猜测导航行为。

优先通过 Elements/可访问性树检查 DOM。必要时在界面上已确认的 DevTools Console 中执行只读 DOM 查询。不要绕过“禁止粘贴”等浏览器安全提示。以下是查询形状，使用前确认当前页面确有这些元素；它们不是网络请求或自动爬虫。

## 列表发现

先记录当前列表 URL、页面条件（分类/线路/排序/页码）、所有可见节目链接以及下一页/更多入口，然后才进入资源页。可用只读查询辅助记录当前 DOM 中的链接：

```javascript
JSON.stringify(Array.from(document.querySelectorAll('a[href]'), a => ({
  text: a.textContent.trim(), url: a.href, target: a.getAttribute('target')
})))
```

识别真实显示为节目详情的链接；当前已验证形状是 `/video2/<id>.html`，遇到其他形状须实际打开一个验证，不把所有站内链接都当资源。去掉纯 fragment 进行去重，保留影响筛选/分页的查询参数。不要猜 ID 范围、拼接未知页码接口或扫描隐藏 API。

全站模式从首页实际存在的分类、线路、公开分页/加载更多进行广度优先发现。当前观察到分类为动漫、剧集、电影、综艺，线路包括量子、非凡、天堂、酷播等，但以后以当时 UI 为准，不以这份观察清单限制或虚构范围。

- 保存公开导航入口与发现的资源页到 `coverage.discovered`。
- 一个列表页的节目链接和后续入口都已读取并保存后，才记 `visited`。
- 点击实际“下一页”或“加载更多”；动态加载应观察 URL、页面标识和新增资源集合。URL 不变的多个 UI 状态，所有状态穷尽后才将该 URL 记为已访问，并在任务批次记录中注明筛选条件/终止证据。
- 若连续动作仅得到同一组链接，检查是否到底/按钮禁用/访问异常；不要仅凭一次空白或网络超时认定到底。
- 每个入口真实耗尽、无待访问页面、无无法解释的访问失败，才设置 `coverage.exhausted=true`。覆盖字段由 Agent 根据现场证据维护，脚本无法替代这个判断。

指定模式只发现匹配范围的资源：指定详情链接处理该页；指定节目使用站内实际搜索 UI 并核实同名/年份；指定分类只遍历该分类；指定集数/日期区间只入队匹配分集。用户给出直接 m3u8 时可跳过站点发现，以该 URL 作 `page_url`、用户标题作 `title`，默认标签 `视频`。

## 资源页提取

确认标题与页面 URL，先识别线路标签与集数列表。已观察的分集结构：

```html
<a class="episode" data-web="https://…/index.m3u8">20251202</a>
```

通过 Elements 或只读 Console 一次记录已加载元素，避免逐集播放才能收集：

```javascript
JSON.stringify({
  page_url: location.href,
  page_title: document.title,
  episodes: Array.from(document.querySelectorAll('#list a[data-web]'), a => ({
    label: a.textContent.trim(),
    url: a.getAttribute('data-web'),
    group: a.closest('[class*="playList"]')?.className || ''
  }))
})
```

`page_title` 可能含站点后缀，应与可见节目名核对。`group` 只是 DOM 分组，不等于线路名；对照真实可见的线路标签后转换为入队字段 `line`，无法确定就留空，不猜“量子”。相对地址用当前页面 URL 解析，但只提交真实存在的 HTTP(S) 地址。

检查折叠、线路切换、分页或“更多集数”是否影响 DOM 内容。AX 的“显示 0–100 项”可能只是工具截断，不是实际总集数。长结果分批读取并核对数量；禁止根据首尾样本补造中间 URL。没有 `data-web` 时才通过本页正常播放操作与 DevTools Network 检查实际媒体请求；不能猜 CDN 路径。

将规范化后的记录写入当前任务批次 JSON，再 `ingest`。成功入队后才标记该资源页已访问。已发现但未能读取的页面保留失败原因，继续其他不受影响页面；全站被验证码阻断时停止浏览并请用户处理。

## 首次扩展前的小样验证

同一标签依次验证：列表→一个已观察详情→提取→返回原列表→真实下一页（若存在）。核实右侧 DevTools 仍在、链接没有丢失、分页确实产生新页面/数据。若用户关闭标签，不抢占浏览器；保存已有资料，报告未验证的部分。首次新线路仅验证一集下载再扩大该线路，失败只在临时目录调整方法，不先修改正式 Skill 试错。
