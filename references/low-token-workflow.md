# 采集短入口：按当前阶段展开

本文件只供采集线程。主线程读 [主线程短流程](main-supervision.md)，不代采或代收批；源码故障修复与测试由主线程按该参考的长期授权边界处理，采集者不自行改代码。健康线程持续使用原owner，只有确认死亡才由主线程调用清理Skill后补位，禁止定时轮换。

01–04直接采集公开页面资源：先续原owner断点，再消费唯一共享详情队列；不足时从本人已观察的实际列表、来源入口和真实下一页补充详情URL。主线程只做恢复和最小监督，不供关键词、不查外部榜单。不创建关键词或榜单发现任务；无法继续时保存断点并内部上报真实阻塞，不循环空claim。

列表片名与状态分开提取：实际DOM为`.weui-media-box__bd`直接文本节点加`p.weui-media-box__desc`时，前者是title，后者是status；不要把整个容器的textContent作为片名，也不要按字符串后缀猜测删除HD。已认领条目若发生拼接错误，保留原claim并将同URL节点证据交主线程纠正，详情标题校验仍严格执行。

## 当前阶段

只执行正式认领的详情采集任务，完成后用既有提交事件和回执内部上报；保留各任务独立认领、进度和原单lane。实际节目、详情URL、来源、线路、分集和资源身份如实保存。未终态的历史搜索只按原任务书和原claim恢复或收尾，不改query、owner、在途动作和证据。

分类职责、入口、核验步骤、系列归组和新分类字段写入从采集规范彻底删除，没有待开启的分类开关。已经保存的节目、资源、分类、系列及关联和证据保持原样，不归档、迁移、删表或改写历史数据；规范修改不改网站或分类程序代码，不干预在途任务，也不恢复暂停采集。

## 共同门禁

从项目根运行现有CLI；OWNER、BATCH、query/channel、任务书和证据路径直接解析正式JSON，不抄PTY折行、不复制历史整段日志。唯一共享状态与claim不另建队列；按返回next_action续原断点，已落盘页面不重采。

只读本人批次统一用`workflowctl.py current --thread OWNER`，复用程序默认的正式共享状态；不手输猜测`--state`路径。该入口直接封装coordctl的current_batch，不领批、不写日志；领批仍用claim-detail，不把idle当停止。

压缩或续回合后，先结合最新明确指令、一次正式`current`、对应任务书与原回执确认当前未终态任务，续原`active_batch`／句柄及真实`next_action`；已ACK、已隔离、已release或已完成核验的旧任务仅作历史证据，不因旧消息或压缩摘要再次执行。

浏览器Node调用显式设置timeout_ms=120000，详情单页及正式搜索模块段设置240000；外层yield仅等待原句柄，未知动作不重放。搜索统一prepare→execute一次→finalize，原模块和actionId保持到真实终态；选中渠道及按钮以当前公开DOM核实。

首次浏览按当前Chrome Skill和 [CUA](cua-workflow.md)初始化，复用同一binding与本人工作标签、单lane。Chrome分组固定叫`01`、`02`、`03`、`04`，不得加“采集线程”或其他后缀；父session与子thread分别记录，不仅凭ID不同判失效。额外本人临时标签用完且无在途再关闭，工作标签需跨回合续跑时按宿主正式handoff机制保留；保护用户和其他线程标签。

范围含成人向，采集什么同步什么，不检查视频内容。技术完整性、去重、独立封面与正式ack门禁继续执行；普通成功仅落程序计数，真实困难交原owner和主线程处理。健康线程不逐批问主线程，不自行生产发布，不新增第五路。

同一任务已读且版本未变的内容复用，只展开当前阶段。日常不读全部参考、全量聊天或全部证据，不循环wait/current/events等待普通回执。

已知故障先用[恢复模板](recovery-templates.md)和`recoveryctl plan`，不重新推演整条链路。正式workflowctl失败自动记录；直接浏览器工具失败由原owner在安全检查点用`recoveryctl record`记录真实工具ID和错误。首次故障时间不因重试或换回合清零，只由新的真实ACK/搜索提交解除。未知工具继续等原句柄，不把超时当作可以重放。工作路径、任务和批次全部解析正式JSON，禁止手输目录以免写入拼错的旁路。

正式入库和搜索提交由程序投递增量事件，主线程授权的单一隐藏CLI负责生产同步；采集者不另起同步器、不上传应用代码、不逐批要求主线程发布。提交回执中的queued/pending不是生产成功，生产成功只认独立验收回执。任一采集槽位连续真实故障超过3600秒后，所有本项目任务停写保留断点，不释放、重领、删除或自动重启。

采集完成并ack后直接续下一批，不追加分类或系列任务，不加载分类Skill或调用分类模型。正常、修复和停工均不向用户汇报，只显示`working`；正式任务、故障证据和验收回执继续保存。
