# 单线程采集短入口

当前执行位置为服务器，生产库为唯一正式库，本地入口已退休。先按[服务器采集](server-collection.md)配置并确认实际宿主，再使用下列原有单线程业务入口；本机不得照抄命令复工。

当前唯一 agent 直接完成 Playwright、入库审计、封面、ACK 与生产增量验收。默认每批一个节目，不创建或调度采集子线程，不使用 CUA 采集。旧 CUA/四路参考仅供历史证据的原断点核验，不能重新启用旧执行方式。

从项目根执行：

```powershell
python -X utf8 -B scripts/collection/single_agentctl.py run --thread OWNER --max-views 2
```

OWNER 必须是当前本线程 `CODEX_THREAD_ID`，并与正式 `state.json` 的主 agent 绑定一致。入口只完成一个有界步骤：先核验原交接 ready 批次，再续本人 claim；没有 claim 时读取真实公开来源最新列表，按 URL 去重，并只在已验收节目出现实际状态变化时重新排队。每批停写后复用正式资源审计、中央独立封面和 ACK；raw/失败/封面待补仍保留真实状态。

每轮只读取 CLI 短结果、对应任务书及回执。`production.pending`、queued 和 executor_live 都不是上线成功；同步须在原生产事件台账出现独立核验成功。不要将整页媒体、完整日志或浏览器代码传回模型。已完成步骤不重复运行，未知原句柄继续等待。

来源按实际公开控件及其可见栏目连续轮询，每个有界步骤最多 8 个视图。无固定轮次间隔；队列有条目顺序继续，空队列立即观察下一来源，只为页面加载、锁和真实故障作必要等待。不创建关键词池，不推断页面或节目地址，不另装常驻监督器或计划任务。编号、空资源和失败页直接跳过，不入节目库，不写 raw/DOM 证据；真实可用资源通过审计与独立封面后才验收、同步和计数。

每个来源先核验真实最新列表；已有可用列表时不再逐片搜索同一轮节目。来源没有可用列表时，仅用该轮实际列表中的两个真实片名做正常站内导航，并保留非空、明确空态或 uncertain 的证据，不宣称全来源穷尽。

返回 waiting_for_public_change 后，使用 `python -X utf8 -B scripts/collection/single_agentctl.py wait --thread OWNER --seconds 45` 有界等待。该命令只等待真实轮次截止，前后检查停工门禁，不启动浏览器、不改进度、不安装服务；只等其原生 session 终态。到期或返回 work_available/discovery_available 时再执行 run；不反复空领或新建后台监督器。

采集只读实际公开 DOM：完整标题、来源、线路、分集、data-web 与指纹；不播放、不 HTTP 抓站点、不推断 opaque ID、不猜 URL、不绕访问限制。详情保持完整计数、连续分段及前后稳定性核验。标题和更新状态分别取自真实节点，导航类别不转成分类。

首次真实故障落 `recoveryctl` 正式台账，重试不清零；连续故障超过 7200 秒或连续第 7 个不同节目无法取得合格封面时，先关闭写闸，再暂停 Goal 并核验专属进程实际退出。用户明确暂停/停止优先。正常运行、修复和停工仅显示 `working`，用户主动提问正常回答。
