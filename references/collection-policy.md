# 单线程公开资源采集原则

2026-10-14 最新用户要求：只将真实可用且通过资源审计和独立封面验收的结果视为节目。未解析编号、空资源及失败页直接跳过，不入节目库、不同步生产、不保存这类采集证据，仅保留必要去重与任务状态。连续访问真实公开来源及可见栏目，无固定检查间隔；下文旧 raw 保存要求以本条为准。

一个当前 agent 顺序负责 Playwright、正式 claim、入库审计、独立封面、ACK 与受控生产增量验收。默认每批一个节目，优先每天稳定更新新增节目和新资源，不使用采集子线程或 CUA。执行见[短入口](low-token-workflow.md)，生命周期见[主线程流程](main-supervision.md)。

仅通过独立隐藏 Playwright 浏览器观察当前公开 DOM，不连接用户共享 Chrome，不使用 HTTP 抓站点、网络拦截、隐藏页面变量、ID 推断或播放。来源与结果绑定同一实际可见视图，标题和状态来自独立节点；完整详情按实际 data-web、原线路/分集、连续索引与前后指纹核验。

实际最新列表中未入队的详情 URL 正常排队；已 ACK 节目只有同标题真实状态发生变化并留存完整 DOM 证据时，才保留原验收与更新历史重新排队。不能猜 ID、伪造新状态、绕过已删除标记或覆盖在途 claim。当前只覆盖真实可见的有界来源视图，不宣称全站穷尽；状态未变化但资源变化的页面尚无自动更新证明，应按明确 URL 范围核验。

保留既有唯一共享协调状态、独占认领、数据库写锁、正式任务书、逐页审计、独立封面和 ACK。模型只读脚本短结果与持久回执，不手写浏览器返回、资源或验收 JSON。raw/失败/封面待补如实保存，不计完整完成。

浏览器 TUN 保持开启，xxmanmi.com/www.xxmanmi.com 与实际核验媒体域名按精确 DOMAIN 规则 DIRECT；不能把规则存在当作真实连接证据。封面仍通过既有解码、质量、去重和独立验收，失败前 1–6 个不同节目允许保留待补跳过，第 7 个立即正式停工，只有真实合格封面成功才清零。

连续真实故障超过 7200 秒先关闭写闸，再暂停 Goal、停止登记执行及核验专属进程退出；重试与回合变化不重置首次故障。idle、空队列和正常锁等待不是死亡。用户暂停/停止优先，不能自动复工。

不写分类、标签或系列归组字段；历史节目、资源、分类、系列关联、所有原 owner/任务/证据和生产用户数据保留。旧搜索/CUA/四路规范仅用于历史证据核验，不产生新的关键词池或榜单供给。

正常、修复、停工仅显示 working，用户主动提问正常回答。只修改规范或只读检查不启动采集；已授权持续任务通过当前原生 Goal 运行，单批完成不结束。
