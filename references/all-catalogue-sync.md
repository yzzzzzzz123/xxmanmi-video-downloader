# 全部节目统一纳管：事件增量与手动全库校准

当前默认已改为[服务器采集与生产库唯一写入](server-collection.md)：用户要求完全在服务器执行，本地库停止维护。下文旧的本地事件增量流程保留作历史资料，不再作为新采集入口。

2026-10-14 最新用户要求优先：真正可用且通过资源审计、独立封面验收的才是节目。编号、空资源、失败页不进入节目库和生产队列，不留这类采集证据；下文旧的 raw/空/失败全部接纳规则不再用于新采集。新条目经完整验收后连续同步，保护已有正常节目、资源及生产用户数据。

本地节目数据全部接纳：空、raw、失败、死记录、旧节目补源、旧排除和现有分类都同步，不再分认可来源。原审计、隔离和认可证据保留，不伪造可播放或门禁成功。

范围为programs、resources、source_observations、program_classifications及已有封面；调度、搜索任务、owner和采集日志不镜像生产。账号、会员、会话、收藏、观看、活动等以生产为准，绝不从本地覆盖。

采集规范已删除分类职责、入口、核验步骤及新分类字段写入要求。已有节目、资源、分类、系列及关联和证据保持原样，不归档、迁移、删表或改写历史记录；同步既有数据不授权研究、补标签或系列归组，缺表不自动创建分类结构。仅规范修改不改程序、不恢复采集、不发布生产。

**入库不等于展示。** 网站所有列表、搜索、来源、推荐、收藏/历史、详情、封面及直达媒体都必须统一执行可用性门禁：已采集、有受支持HTTPS资源、无已知失败/失效且封面有效。all或直接ID不能绕过；隐藏不删除数据库行和生产用户状态。资源可能变化，不宣称永久可播放。

## 正常：入库事件增量，不调用模型

```powershell
python -X utf8 -B scripts/collection/production_live.py status
python -X utf8 -B scripts/collection/production_live.py kick --authorized
```

授权持续采集时，正式提交和封面收尾投递live-events.json；同节目合并成递增版本，启动有界隐藏CLI，不加永久服务或定时器，不等待300。既有单写锁串行处理，每包最多500个真实ID、每次最多四包。第一次启用先用prime --since <已核实全库基线时间> --authorized补齐基线后变更；prime仅入队，不写生产。

正式本地数据库写入前先保存dirty意图，写后投递事件；主线程pulse按真实ACK/搜索提交回执补偿被中断的写后通知，不重采数据。每包冻结所选节目四张管理表全部字段与关联行、已有封面哈希。不用认可/采集/封面状态筛掉记录，也不按last_seen吞掉范围内旧字段修正。检查实际生产目标、身份/自然键、结构、权限、空间与应用状态；先做可读数据库/应用/差异封面备份，再单事务受控合并，不清库、不整库恢复、不改ID、不删除生产独有行。结构不兼容转项目发布Skill；增量不执行DDL、不部署应用、不重启服务。

成功必须核对所选范围全部行、全部导出字段CSV SHA-256、封面哈希、采集计数、权限和实际API验收，再独立读生产核对冻结包。只有事件版本相同才清除待办，发布中更新的事件继续保留。失败保留同一包并有界退避，由下次提交或主线程pulse继续，不让模型重复打包。

固定包已标记 `verified` 但缺少 `independent_verified_at` 时，先对该原包执行独立核验，再处理新事件；不能重新 prepare 后把 `already_aligned` 当作原包的独立回执，否则会反复计入旧事件并阻塞新队列。累计 `verified_events` 是执行计数，不作为不同节目数量或采集完成证明；历史计数与故障回执保留。

API验收遵循当前网站访问规则：匿名标题卡片列表`/api/programs`应返回有效公开目录，不能把它的200响应判为鉴权故障。节目详情与媒体仍必须拒绝无会话访问；媒体探针使用本轮已核验节目实际对应的资源ID，并禁止跟随重定向到片源。公开目录通过不代替受保护接口的401/403核验，也不创建或修改生产用户会话。

catalogue-live-current.json为固定增量包；回执必须明确verification_scope=delta和program_ids，不能声称全库当前一致。queued、执行器存在或待办为0都不是全库对齐证明。正常、修复和停工均不向用户汇报，只显示working；实际验收回执保留。

## 用户明确要求全库对齐时

```powershell
python -X utf8 -B scripts/collection/catalogue_align.py prepare --authorized
python -X utf8 -B scripts/collection/catalogue_align.py publish --authorized
python -X utf8 -B scripts/collection/catalogue_align.py verify
```

手动完整一致性快照保留catalogue-alignment-current.json与原回执；身份、事务、备份和用户数据保护与增量相同，verify实际核对整库范围。必要结构和权限变更按项目发布Skill显式核对，缺表不自动新增或恢复分类结构。仅同步不恢复暂停采集、不部署应用。旧100/300冻结轮、排除账本和历史豁免保留真实状态，但不再筛选新同步。

任一采集槽位真实故障超过两小时触发停止后，关闭新增写入和同步启动，已开始事务安全收尾，队列、原冻结包和全部采集断点保留。只有用户明确恢复才继续。
